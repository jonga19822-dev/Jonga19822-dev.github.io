홈 서비스 약관

짱이 영상 업로더(이하 "본 도구")는 운영자가 본인의 유튜브 채널 짱이주식시황에 시황 브리핑 영상을 자동으로 올리기 위해 만든 개인용 프로그램입니다. 본 도구는 운영자 본인의 PC에서만 실행되며, 운영자 외의 사용자를 받지 않습니다.

1. 수집·이용하는 정보

본 도구는 이름, 연락처, 결제정보 등 개인정보를 별도로 수집하지 않습니다. 다음 항목만 취급합니다.

  • Google 계정 인증 정보 — Google OAuth 2.0을 통해 발급받는 액세스 토큰 및 갱신 토큰
  • 요청 권한 — https://www.googleapis.com/auth/youtube

이 권한은 운영자 본인 채널에 대한 영상 업로드, 썸네일 설정, 재생목록 추가에만 사용합니다. 시청 기록, 구독자 정보, 댓글, 수익 데이터 등 다른 정보에는 접근하지 않습니다.

2. 이용 목적

  • 운영자 본인 채널에 브리핑 영상 및 쇼츠 업로드
  • 업로드한 영상의 썸네일 설정 및 재생목록 등록

위 목적 외의 용도로는 사용하지 않습니다.

3. 보관 및 파기

  • 인증 토큰은 운영자 본인 PC의 로컬 파일에만 저장됩니다.
  • 외부 서버나 클라우드로 전송·백업하지 않습니다.
  • 운영자가 권한을 철회하거나 토큰 파일을 삭제하면 즉시 파기되고 더 이상 사용할 수 없습니다.

4. 제3자 제공 및 위탁

본 도구는 취급하는 정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다. 영상 업로드를 위해 YouTube Data API를 호출하는 것 외에 외부로 나가는 통신은 없습니다.

5. 쿠키·분석·광고

본 도구와 이 웹사이트는 쿠키를 사용하지 않으며, 접속 분석 도구나 광고 스크립트를 설치하지 않습니다.

6. 권한 철회 방법

Google 계정에 부여된 본 도구의 접근 권한은 아래에서 언제든지 철회할 수 있습니다.

https://myaccount.google.com/permissions

철회하면 본 도구는 즉시 채널에 접근할 수 없게 됩니다.

7. Google API 서비스 사용자 데이터 정책

본 도구의 Google API 정보 이용은 Google API 서비스 사용자 데이터 정책을 따르며, 여기에는 제한적 사용 요건(Limited Use)이 포함됩니다.
